Política de Privacidade

Última atualização: 30 de agosto de 2026

1. Quem somos

Este site é operado por Rhuan Freire, engenheiro de software independente baseado em São Paulo, Brasil. Para contato: LinkedIn.

2. Quais dados coletamos

Este site é um portfólio informativo e não coleta dados pessoais diretamente — não há formulários de cadastro, login ou campos de entrada de dados.

Os seguintes dados são coletados de forma automática e agregada por ferramentas de terceiros:

  • Páginas visitadas e tempo de permanência
  • Origem do acesso (busca orgânica, direto, referência)
  • Tipo de dispositivo, navegador e sistema operacional
  • País e cidade aproximada (sem geolocalização precisa)
  • Cliques em elementos interativos (botões, links de trabalhos)

3. Como usamos esses dados

Os dados coletados são usados exclusivamente para:

  • Entender quais conteúdos são mais acessados
  • Melhorar a experiência de navegação do site
  • Acompanhar o desempenho do site nos motores de busca

Nenhum dado é usado para publicidade segmentada, vendido a terceiros ou compartilhado fora das ferramentas descritas abaixo.

4. Ferramentas de terceiros

Google Analytics 4 (GA4)
Usamos o Google Analytics 4 para análise de tráfego. O GA4 coleta dados de forma agregada e anonimizada. O endereço IP é anonimizado automaticamente. Saiba mais na Política de Privacidade do Google.

Google Search Console
Ferramenta do Google para monitorar a presença do site nos resultados de busca. Não coleta dados de usuários individuais do site.

5. Cookies

Este site utiliza cookies de análise do Google Analytics 4. Esses cookies são:

  • _ga — identifica sessões únicas (expira em 2 anos)
  • _ga_XXXXXXXX — mantém o estado da sessão (expira em 2 anos)

Você pode desativar cookies a qualquer momento nas configurações do seu navegador ou instalar a extensão Google Analytics Opt-out.

6. Seus direitos (LGPD)

De acordo com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018), você tem direito a:

  • Confirmar a existência de tratamento de dados
  • Acessar seus dados
  • Solicitar a correção de dados incompletos ou desatualizados
  • Solicitar a eliminação dos dados coletados
  • Revogar o consentimento a qualquer momento

Como este site não coleta dados pessoais identificáveis diretamente, a maioria das solicitações deve ser direcionada ao Google. Para dados do GA4, use as ferramentas de privacidade do Google em myaccount.google.com/privacy.

7. Transferência internacional de dados

Os dados coletados pelo Google Analytics podem ser processados em servidores fora do Brasil, incluindo os Estados Unidos. O Google adota salvaguardas adequadas conforme as regulamentações aplicáveis.

8. Retenção de dados

Os dados de análise são retidos por até 14 meses no Google Analytics, após os quais são automaticamente excluídos.

9. Alterações nesta política

Esta política pode ser atualizada periodicamente. A data de "última atualização" no topo desta página indica quando a versão atual entrou em vigor.

10. Contato

Para exercer seus direitos ou tirar dúvidas sobre privacidade, entre em contato via LinkedIn.
